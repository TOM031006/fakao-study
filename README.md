# 法考学习追踪器 ⚖️

基于**间隔重复（SM-2）算法**的智能法考练习系统。纯本地静态网页，双击 `index.html` 即可使用。

## 功能特点

- 📊 **仪表盘**：学习统计概览、考试准备度、薄弱环节分析
- 📝 **每日练习**：基于智能算法自动出卷，优先推送薄弱知识点和到期复习题
- 📚 **分科练习**：按18+科目逐一攻克，支持知识点级别追踪
- 🔄 **错题复习**：自动收集低正确率题目，结合间隔重复安排复习
- 📈 **学习分析**：科目掌握度、学习趋势、题型表现、考试准备度
- 📥 **题库导入**：支持文本粘贴/PDF上传/Word上传三种方式扩充题库
- ⚙️ **数据管理**：JSON导出备份、一键恢复

## 使用方法

### 启动
双击打开 `index.html`（建议使用 Chrome 或 Edge 浏览器）

### 每日练习
点击"每日练习"开始今日测试，答题后即时显示对错和解析。完成后显示成绩。

### 导入真题
1. 点击"题库导入"
2. 选择导入方式（推荐"粘贴文本"，格式最可控）
3. 按照提示格式粘贴题目
4. 预览解析结果
5. 确认导入

文本导入格式：
```
---
类型: 单选
科目: 刑法
知识点: 犯罪构成
年份: 2023
难度: 3
---
题干内容...
A. 选项A内容
B. 选项B内容
答案：B
解析：解析内容...
```

### 数据备份
在"设置"页面点击"导出全部数据"，会自动下载JSON备份文件。

## 科目覆盖

- **试卷一**：法治思想、法理学、宪法、中国法律史、国际法、司法制度和法律职业道德、刑法、刑事诉讼法、行政法与行政诉讼法
- **试卷二**：民法、知识产权法、商法、经济法、环境资源法、劳动与社会保障法、国际私法、国际经济法、民事诉讼法

## 技术说明

- 纯前端静态页面，无需服务器
- 数据存储在浏览器 localStorage 中
- 使用 Chart.js 绘制统计图表（CDN加载）
- PDF导入使用 PDF.js（CDN）
- Word导入使用 mammoth.js（CDN）
